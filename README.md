# ⚖️ Marques & Barroso Advocacia

> **Landing Page corporativa focada em performance, autoridade e conversão.**

O **Marques & Barroso** é um projeto frontend desenvolvido como Prova de Conceito (PoC) para prospecção B2B. O objetivo é demonstrar como uma arquitetura web moderna pode elevar a percepção de valor de um escritório de advocacia tradicional, unindo design sofisticado e captação inteligente de *leads*.

O projeto foi construído com **Next.js e TypeScript**, focado em renderização estática (SSG) para máximo desempenho em SEO, com estilização em **Tailwind CSS**.

---

## 📖 Sobre o projeto

Escritórios de advocacia frequentemente enfrentam o desafio de modernizar sua comunicação digital sem perder a sobriedade. Muitas vezes, websites jurídicos sofrem com carregamento lento, falta de responsividade e baixa otimização para captação de clientes.

Esta Landing Page soluciona esse problema oferecendo uma experiência de usuário (UX) impecável. O cliente em potencial pode navegar fluidamente pelas áreas de atuação do escritório, conhecer a equipe e entrar em contato de forma rápida, tudo com um carregamento quase instantâneo.

---

## 🎯 Objetivos

* **Autoridade Visual:** Aplicar conceitos avançados de UI/UX voltados para o nicho jurídico e corporativo;
* **Performance e SEO:** Garantir notas máximas no *Core Web Vitals* do Google utilizando a arquitetura do Next.js;
* **Conversão:** Otimizar a captação de *leads* através de CTAs estratégicos e gatilhos de WhatsApp;
* **Escalabilidade:** Criar uma estrutura de componentes pronta para futura integração com um Headless CMS.

---

## ✨ Estrutura e Funcionalidades

A página foi construída em sessões estratégicas (Single Page Application):

* 🏢 **Apresentação (`Hero`, `About`):** Impacto visual imediato e introdução da metodologia da banca;
* ⚖️ **Especialidades (`PracticeAreas`):** Exibição clara e categorizada das áreas de atuação do direito;
* 👥 **Corpo Jurídico (`Lawyers`):** Apresentação dos sócios, transmitindo credibilidade;
* 📊 **Prova Social (`Stats`, `Testimonials`):** Contadores animados e depoimentos para reforçar autoridade;
* 📞 **Captação (`ContactForm`, `WhatsAppButton`):** Formulário de contato estruturado e botão flutuante para atendimento ágil.

---

# 📂 Estrutura do projeto

O projeto adota o **App Router** do Next.js com uma separação clara entre componentes de interface e dados:

```text
site/
│
├── app/
│   ├── globals.css        
│   ├── layout.tsx         
│   └── page.tsx           
│
├── components/            # Módulos visuais isolados (Hero, Contact, etc.)
│
├── lib/
│   └── data.ts            # Centralização dos dados (Mock CMS)
│
└── public/                # Assets e imagens
```
